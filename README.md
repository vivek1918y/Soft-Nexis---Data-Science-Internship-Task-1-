## Project Overview

This repository contains an end-to-end data cleaning and preprocessing pipeline built as part of my Data Science Internship. Raw datasets often contain duplicates, missing values, incorrect data types, and formatting errors that distort analysis. This project automates a systematic 6-step cleaning methodology to transform messy raw data into structured, analysis-ready formats.
